## Установка

### На любой платформе через Bun (рекомендуется)

Установите [Bun](https://bun.com) и выполните:

```bash
bun install -g vibe-tavern
```

Запустите Vibe Tavern командой `vibe-tavern`

Другие способы установки смотрите в [Быстрый старт](#быстрый-старт)

## Что такое Vibe Tavern?

Vibe Tavern — локальный клиент для AI-ролеплея, который мы делаем с упором на постоянное использование, долгие сессии и мобильные экраны.

Нам хотелось, чтобы повседневные действия не требовали блужданий в множестве меню, сборка промпта была простой и прозрачной, а персонажей можно было полноценно разрабатывать внутри приложения.

Вы используете собственные API-ключи, данные остаются на вашем компьютере, а почти всё важное можно проверить, изменить или отключить.

> [!NOTE]
> Проект активно развивается. Перед обновлением всё ещё стоит делать резервную копию директории data.

## TLDR

- **Интерфейс для комфортного использования** — избранные модели, персоны, пресеты и контекстный бюджет доступны прямо из чата.
- **Полноценная работа с персонажами** — простой текст, Markdown-редактор с визуальными секциями, версии персонажа, импорт карточек и AI-разбор черновиков.
- **Соавтор** — отдельный чат, где можно обсуждать карточку персонажа, подключать скиллы и применять предложенные моделью правки только после просмотра.
- **Простые и прозрачные промпты** — простой режим, визуальная канва для продвинутой сборки и честная трассировка промпта итогового запроса.
- **Память и игровые системы** — сводки, трекер целей, трекер сцены и броски кубиков, результаты которых становятся частью конкретного хода.
- **Лорбуки и JS-скрипты** — от быстрого создания записей до сложной условной логики, случайных событий и состояния персонажа.
- **Локальный запуск и мобильный доступ** — один процесс, свои провайдеры, QR-доступ по локальной сети и отдельный мобильный интерфейс.

## Чат, которым удобно пользоваться каждый день

Не хочется каждый раз открывать настройки провайдера, чтобы сменить модель? Добавьте нужные модели в избранное и переключайте их прямо из поля ввода. Там же можно одной кнопкой поменять персону или пресет промпта.

Прямо над полем ввода видно, сколько контекста уже занято. Если открыть разбивку, станет понятно, сколько съели история, персонаж, лорбуки, сводки и остальные слои.

Очередь генераций позволяет отправить несколько запросов подряд и не ждать окончания каждого вручную.

## Персонажи и Соавтор

Персонажа можно редактировать двумя способами: через обычный текст или в полноценном Markdown-редакторе.

Markdown-редактор закрепляет канонические заголовки карточки, чтобы их нельзя было случайно удалить или превратить в текст, который потом невозможно нормально разобрать при сборке промпта.

Поддерживается импорт PNG и JSON-карточек SillyTavern V2/V3, а также Markdown. Если вместо аккуратной карточки у тебя свалка из заметок, кусков прозы и старых диалогов, AI-помощник попробует распознать поля и покажет, как именно он их разложил. Если результат странный — можно поменять таргет промпта, модель или температуру и прогнать разбор ещё раз.

Версии персонажа позволяют вести несколько независимых вариантов одной карточки: базовый, более агрессивный, романтический или любой другой. Каждая версия — полноценный снимок, между которым можно переключаться без копирования персонажа вручную.

Соавтор превращает редактирование карточки в отдельный рабочий чат. С моделью можно обсудить концепт, характер, сценарий, голос и приветствия, подключить подходящие скиллы с шаблонами и ассетами, а затем получить предложения по изменению. Изменения не применяются сразу: сначала показывается diff, после чего можно принять весь результат или только нужные фрагменты.

## Промпт — сердце проекта

По умолчанию менеджер промптов работает в простом режиме: написал системный промпт в поле, выбрал нужные настройки и пошёл играть.

Для тех, кому этого мало, есть продвинутый режим с визуальной канвой. В нём можно перетаскиванием задать точную очередность слоёв, включая инъекции на определённой глубине истории, и одновременно видеть позиции персонажа, лорбуков, сводок и пользовательских промптов.

Трассировка промпта показывает не красивую схему намерений, а реальный итог сборки: какие слои вошли в запрос, в каком порядке, почему активировалась конкретная запись лорбука и сколько токенов занял каждый источник.

Поддерживаются системный промпт, jailbreak, prefill, author's note, summary prompt, tools prompt и собственные depth-инъекции. Пресеты можно импортировать и экспортировать в совместимом с SillyTavern формате.

Макросы `{{user}}`, `{{char}}`, `{{if}}`, `{{setvar}}`, `{{roll}}` и вложенные блоки разбираются полноценным парсером, а не набором замен по регуляркам.

## Память — мозг проекта

Можно выбрать, сколько последних сообщений отправлять модели, создавать несколько ручных или AI-сводок и отдельно решать, какие из них попадут в контекст.

Автоматическая компакция генерирует сводки в фоне через выбранную модель и умеет исключать уже пересказанные сообщения. Интерфейс показывает, сколько токенов занимал бы полный контекст и сколько удалось освободить.

Служебные модели не обязаны совпадать с основной. Можно отдать тяжёлый RP-вызов любимой модели, а сводки и трекеры — более быстрой и дешёвой.

## Дополнения чата

Система кубиков работает перед отправкой пользовательского сообщения и не просит основную модель изображать случайность.

Скрипт персонажа может объявить один или несколько проверочных бросков для активной персоны или персонажа. Пользователь бросает нужные кубики в панели над полем ввода, при необходимости перебрасывает или фиксирует результат, а затем отправляет сообщение.

Принятый результат навсегда привязывается к этому пользовательскому ходу, показывается в истории и ровно один раз попадает в промпт для всех вариантов следующего ответа. Регенерация ответа не меняет уже состоявшийся бросок.

Если готовых Dice-скриптов нет, начать можно со встроенного шаблона Кость Судьбы.

Трекер целей хранит цели персонажа в конкретном чате. Отдельная модель проверяет прогресс параллельно с основным RP-вызовом, а актуальные задачи возвращаются в контекст, чтобы персонаж не забывал, чего он вообще пытался добиться.

Трекер сцен поддерживает структурированное состояние сцены: место, участников, предметы, внешний вид и другие детали, на которых модели часто спотыкаются в длинной игре. Состояние привязано к конкретному варианту ответа и обновляется фоновой моделью, не задерживая основной ответ персонажа.

## Лорбуки

По умолчанию редактор записи показывает только то, что нужно для быстрого старта: ключи и текст. Полный режим раскрывает продвинутые параметры настройки лорбуков.

Записи с одинаковой позицией можно перетаскивать, задавая порядок между ними. Активированные записи видны в трассировке промпта вместе с причиной срабатывания.

Если чистый лист победил, встроенный AI-помощник может написать текст записи и отдельно сгенерировать первичные или вторичные ключи.

Импорт и экспорт совместимы с форматом SillyTavern.

---

## JS-скрипты

В Vibe Tavern есть редактор JS-скриптов с песочницей и Janitor AI-совместимым API. Скрипты могут читать состояние текущего контекста, реагировать на ключевые слова и добавлять собственные слои в промпт.

Проще всего воспринимать их как очень продвинутый лорбук: встретилось условие — выполнилась логика, изменилось состояние или появился дополнительный контекст.

Так можно делать случайные события, трекеры, циклы, скрытые механики и броски, которые действительно фиксируются, а не меняются при каждой регенерации.

Можно использовать встроенные шаблоны, импортировать совместимые скрипты или попросить AI-помощника написать основу по обычному текстовому описанию.

## Провайдеры

Настройка провайдера начинается с трёх вещей: выбор протокола, указание ключа и проверка соединения. Поддерживается большинство провайдеров и типов эндпоинтов.

Для разных моделей одного профиля можно сохранить разные настройки сэмплеров. Любимые модели закрепляются для быстрого переключения из чата.

По желанию вы можете настроить отдельную vision-модель (если они есть у провайдера). Эта модель будет описывать ваши изображения если ваша основная модель не поддерживает мультимодальный ввод.

## Темы, изображения и мобильный доступ

В интерфейсе пять встроенных тем: Milk Coffee, Coffee, Mystic Night, Mystic Dawn, Light Lava и Dark Lava. Среди них есть светлые, тёмные, спокойные и более декоративные варианты; переключение находится в настройках интерфейса.

В чат можно прикреплять изображения. Vision-модель описывает их для основной модели, а в лайтбоксе можно посмотреть оригинал, приблизить его и при необходимости отредактировать описание.

Для доступа с телефона достаточно открыть Мобильный доступ и отсканировать QR-код. В локальной сети или через Tailscale/VPN (удалённый API защищён токеном).

Мобильная версия имеет полностью адаптированный вид.

Для Android доступна сборка под Termux, автоматизирующая основную часть установки.

## Быстрый старт

### Windows

Скачайте установщик из [Releases](https://github.com/Noineri/vibe_tavern/releases), запустите его и установите Vibe Tavern как обычное приложение.

Если установка не нужна, скачайте portable-архив, распакуйте его и запустите `Vibe Tavern.exe`.

### Linux

Скачайте архив `.tar.gz` из [Releases](https://github.com/Noineri/vibe_tavern/releases), распакуйте его и запустите `./vibe-tavern`.

### Docker

```bash
docker compose up -d
```

### Android

Используйте APK-сборку под Termux. Подробности — в [гайде по установке](docs/android-setup-ru.md).

### Запуск из исходников

Понадобятся Git и Bun.

```bash
git clone https://github.com/Noineri/vibe_tavern
cd vibe_tavern
bun install --frozen-lockfile
bun run dev
```

Персонажи, чаты, настройки и ассеты хранятся локально:
 - `AppData\Local\VibeTavern` (Windows)
 - `~/.local/share/vibe-tavern` (Linux).

Vibe Tavern — однопроцессный Bun-монолит: React SPA, Hono API и SQLite работают как одно приложение без отдельного сервера базы данных.

Как запустить проект, где лежат пакеты и какие правила действуют для изменений, описано в [`CONTRIBUTING.md`](./CONTRIBUTING.md). Подробная архитектура находится в [`docs/architecture/`](docs/architecture/).
