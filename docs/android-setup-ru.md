# Руководство по настройке на Android

Vibe Tavern работает локально на ARM64-устройствах Android через Termux и proot Ubuntu.

APK устанавливает локальный сервер и управляет им, а интерфейс Vibe Tavern открывается в обычном браузере телефона.

## Требования

- Android-устройство с процессором ARM64;
- Termux из [F-Droid](https://f-droid.org/packages/com.termux/), а не заброшенная версия из Play Store;
- около 500 МБ свободного места для Ubuntu и Vibe Tavern;
- разрешение на установку APK, скачанного из GitHub Releases.

## Первичная настройка

### 1. Установи и подготовь Termux

Установи Termux из F-Droid, открой его и дождись появления первой командной строки.

При обычной настройке обновлять пакеты вручную не нужно: установщик Vibe Tavern сам выполняет неинтерактивное обновление с повторными попытками перед установкой необходимых инструментов.

### 2. Разреши Vibe Tavern запускать команды Termux

Выполни внутри Termux:

```sh
mkdir -p ~/.termux
printf '%s\n' \
  'allow-external-apps=true' \
  >> ~/.termux/termux.properties
termux-reload-settings
```

Затем введи `exit`, смахни Termux из списка недавних приложений, снова открой его и дождись командной строки, чтобы настройка вступила в силу до возвращения в Vibe Tavern.

### 3. При необходимости выполни одноразовый переход на постоянную подпись

Если установлен старый предварительный или debug-лаунчер Vibe Tavern, Android не сможет обновить его до официальной сборки с постоянной подписью.

Один раз удали только старое Android-приложение и установи первый официальный APK из GitHub Releases.

Не используй **Удалить Vibe Tavern** или **Удалить всё** для этого перехода: эти действия специально удаляют серверные данные.

Удаление только Android-лаунчера оставляет данные внутри Termux нетронутыми.

Все последующие официальные APK используют тот же пакет и ключ подписи, поэтому устанавливаются поверх предыдущей версии.

### 4. Установи официальный APK

Скачай точный файл `Vibe-Tavern-vX.Y.Z-android.apk` из [GitHub Releases](https://github.com/Noineri/vibe_tavern/releases), установи его и открой Vibe Tavern.

Выдай разрешение **Run commands in Termux environment**, когда Android его запросит.

Если Android скрывает это разрешение за ограниченными настройками, используй кнопку настроек в лаунчере, выбери в меню страницы приложения **Разрешить ограниченные настройки**, включи **Выполнение команд в среде Termux** в списке всех разрешений, затем вернись и нажми **Продолжить**.

Если лаунчер сообщает, что Termux или разрешение отсутствует, используй показанную кнопку установки/настроек и затем вернись в лаунчер.

### 5. Установи встроенный сервер

Нажми **Установить сервер vX.Y.Z**.

Лаунчер откроет видимую сессию Termux, которая:

- неинтерактивно обновит необходимые пакеты Termux, сохраняя локальные конфигурационные файлы;
- установит `curl`, `tar`, `proot-distro` и `procps`;
- создаст или повторно использует зафиксированный контейнер Ubuntu 24.04;
- передаст встроенный архив через временный localhost foreground-сервис без разрешения на хранилище и копии в Downloads;
- проверит и распакует ARM64-сервер, встроенный в APK;
- установит файлы программы в `~/vibe-tavern` внутри Ubuntu;
- сохранит пользовательские данные в `~/.local/share/vibe-tavern`;
- запустит сервер.

Первичная установка Ubuntu может занять несколько минут в зависимости от устройства и сети.

Временное уведомление **Подготовка встроенного сервера для Termux** исчезает после получения архива Termux.

## Ежедневное использование

Нажми **Запустить сервер в Termux**, чтобы открыть видимую диагностическую сессию и запустить локальный сервер.

Нажми **Открыть в браузере**, чтобы перейти на `http://127.0.0.1:8787`.

Не закрывай Termux во время работы с Vibe Tavern: принудительное закрытие или смахивание приложения может остановить сервер.

Нажми **Остановить сервер**, чтобы завершить только точный процесс Vibe Tavern.

## Обновление лаунчера и сервера

Обновление лаунчера и обновление сервера — два отдельных явных шага.

### Обновление APK-лаунчера

Лаунчер проверяет последний публичный стабильный GitHub Release один раз за запуск процесса, а кнопка **Проверить обновление лаунчера** запускает ручную проверку.

GitHub-токен не требуется.

Автоматическая проверка никогда ничего не скачивает.

Когда обновление доступно:

1. проверь версию и примечания к релизу;
2. нажми **Скачать APK**, чтобы подтвердить загрузку;
3. дождись завершения Android `DownloadManager`;
4. если потребуется, разреши Vibe Tavern устанавливать неизвестные приложения в настройках Android;
5. подтверди обновление в системном установщике Android;
6. снова открой Vibe Tavern после установки.

Отмена предложения или системной установки оставляет текущий лаунчер работоспособным.

После повторного открытия лаунчер подключается к уже начатой загрузке, а не создаёт дубликат.

### Обновление встроенного сервера

Установка нового APK не заменяет серверный payload автоматически.

После открытия нового лаунчера появляется кнопка **Обновить сервер до vX.Y.Z**, если установленная версия сервера старее или неизвестна.

Нажми её явно и дождись завершения установки в видимой сессии Termux.

Обновление заменяет только `~/vibe-tavern`; чаты, персонажи, настройки, сводки и ассеты остаются в `~/.local/share/vibe-tavern`.

После завершения запусти или открой Vibe Tavern и убедись, что версии лаунчера и сервера совпадают.

## Варианты удаления

**Удалить Vibe Tavern** удаляет файлы программы и все пользовательские данные Vibe Tavern, но оставляет контейнер Ubuntu.

**Удалить всё** удаляет весь контейнер proot Ubuntu вместе с данными Vibe Tavern.

Удаление только Android APK через настройки Android не запускает эти разрушительные действия.

## Решение проблем

### `CANNOT LINK EXECUTABLE curl` или ошибки SSL

Обнови пакеты Termux командой `apt update && apt full-upgrade`, полностью перезапусти Termux и повтори попытку.

### Кнопки лаунчера ничего не делают

Проверь, что Termux установлен из F-Droid, строка `allow-external-apps=true` присутствует, Termux был перезапущен, а Android выдал Vibe Tavern разрешение **Run commands in Termux environment**.

Если Termux был принудительно остановлен, открой его один раз, дождись командной строки, вернись в Vibe Tavern и повтори действие.

### Установщик сообщает, что зеркало не выбрано, хеш репозитория не совпадает или зеркало синхронизируется

Выполни `termux-change-repo` в Termux, выбери другое зеркало и повтори **Установить сервер** или **Обновить сервер**.

### Установщик сообщает, что контейнер `ubuntu` не установлен

Вернись в Vibe Tavern и повтори установку с текущим лаунчером: он проверяет точные имена контейнеров и устанавливает зафиксированный образ Ubuntu 24.04, если `ubuntu` отсутствует.

### Передача встроенного архива прервана

Вернись в Vibe Tavern и повтори **Установить сервер** или **Обновить сервер**. Архив передаётся приватно через `127.0.0.1`; разрешение Termux на хранилище и файл в Downloads не требуются.

### Android отказывается обновлять лаунчер

При переходе на первый официальный релиз с постоянной подписью один раз удали старый debug-лаунчер и установи официальный APK вручную.

Для последующих релизов проверь, что скачан точный Android APK из официального GitHub Release и что Android разрешает Vibe Tavern устанавливать неизвестные приложения.

### Загрузка была прервана

Снова открой Vibe Tavern: лаунчер восстановит сохранённую задачу `DownloadManager` и предложит установку, когда APK будет готов.

### Обновление сервера завершилось ошибкой

Прочитай или скопируй диагностику из видимой сессии Termux и проверь `~/vibe-tavern-install.log` в домашней директории Termux.

Если проверка не проходит, установка останавливается до атомарной замены директории программы, поэтому предыдущая программа и отдельные пользовательские данные остаются нетронутыми.

### Браузер не открывается

После запуска сервера открой `http://127.0.0.1:8787` вручную в любом браузере.

### Веб-интерфейс тормозит или останавливается

Отключи оптимизацию батареи для Termux, оставляй его сессию в списке недавних приложений и отключи агрессивные режимы энергосбережения производителя.

## Архитектура и расположение файлов

APK — оркестратор сервера, а не WebView-клиент.

Он запускает предкомпилированный ARM64-сервер в proot Ubuntu и передаёт отображение интерфейса, клавиатуру, загрузки и cookies системному браузеру.

На устройстве не выполняются `git clone`, `bun install` или сборка из исходников.

Во время установки временный foreground-сервис передаёт встроенный архив в Termux через `127.0.0.1` и останавливается после успешной передачи; архив не сохраняется в общем хранилище.

| Путь внутри proot Ubuntu | Содержимое |
|---|---|
| `~/vibe-tavern/` | Заменяемые файлы программы: сервер, веб-ассеты, миграции, промпты и токенизаторы |
| `~/.local/share/vibe-tavern/` | Постоянные данные: база, персонажи, чаты, сводки, настройки и ассеты |
| `~/start-vibe-tavern.sh` | Сгенерированный скрипт запуска сервера |

| Лог в домашней директории Termux | Назначение |
|---|---|
| `~/vibe-tavern-install.log` | Установка сервера и обновления payload |
| `~/vibe-tavern-start.log` | Диагностика запуска сервера |
| `~/vibe-tavern-stop.log` | Диагностика остановки |
| `~/vibe-tavern-uninstall.log` | Диагностика удаления |
